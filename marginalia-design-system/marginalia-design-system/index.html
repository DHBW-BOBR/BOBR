Marginalia
Gestaltungsregeln Tokens README

Marginalia ist das Design System für ein Werkzeug, das Literaturverzeichnisse wissenschaftlicher Arbeiten prüft: Autoren, Jahr, Titel, Zeitschrift, Seiten und DOI werden mit Referenzquellen abgeglichen, fehlerhafte und fehlende Angaben markiert und Widersprüche zwischen Quellen sichtbar gemacht.

Warmes Papier statt grellem Weiß, Serifen für die Werke, eine leise Bedienung. Alle Komponenten sind reines CSS mit dem Präfix mg-.
